# Photo Showcase

A simple HTML project that demonstrates accessible image markup, captions, and embedded video using HTML5 elemets.

## Project Overview

This project showcases a collection of photos and media while following accessibility and semantic HTML best practices.

The page includes:
- Semantic page structure
- Image gallery with descriptive alt text
- Figure captions for additional context
- Decorative image handling
- Embedded video with controls and fallback content
